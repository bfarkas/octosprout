# OctoSprout workspace

This is a private [OctoSprout](https://github.com/bfarkas/octosprout) workspace:
Markdown records in Git. Captures, ideas, tasks, projects, decisions, research,
experts and proposals live here; the application lives in the public
`octosprout` repository.

```text
records/captures/YYYY/MM/   raw captures (the Inbox is captures with status "new")
records/ideas/              ideas
records/tasks/              tasks
records/projects/           projects
records/decisions/          architecture decision records
records/research/           research notes
experts/                    expert profiles
proposals/YYYY/MM/          proposed changes and their signed approvals
skills/                     agent skills
prompts/                    reusable prompts
```

Check the workspace with `octosprout validate`. CI runs the same check on every push.
