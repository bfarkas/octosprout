# Starter templates

Copied into a new workspace by `octosprout init` (spec §5.1).

- `workspace/`: files copied as-is to the workspace root (`README.md`, `octosprout.yaml`, `.gitignore`, the validation workflow)
- `agents/`: starter `AGENTS.md` and `CLAUDE.md` (§16.1)
- `prompts/`: the ChatGPT handoff brief: the `/octosprout` Custom Instructions command and a one-off prompt (§16.4, Appendix B)
- `adr/`: the vendored upstream ADR template and its MPL-2.0 notice (§13.1)
- `records/`: record templates. `{{ID}}`, `{{TITLE}}` and `{{NOW}}` are filled in at creation.
- `skills/`: starter skills (§16.2)
